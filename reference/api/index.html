    API Reference¶

    This page provides the complete API reference for QuranKit.

    Core Classes¶

    Quran¶

    Main entry point for accessing Qur'anic text and analysis.

    Quran ¶

    Bases: BaseModel

    Main interface for accessing Qur'anic text.

    This class provides methods to load datasets, retrieve surahs and ayahs, and perform searches. It maintains the current dataset and edition context.
